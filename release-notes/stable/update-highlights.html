Recent Update Highlights

Curated highlights from the rolling stream — things with visible impact or required attention. Fine-grained history: repo Changes.md.

Recovery Environment expansion

The Windows-RE-style maintenance mode keeps growing: Timeshift browse/restore, package repair pipelines, GRUB repair for BIOS+UEFI with dual-boot os-prober, fstab regeneration, password reset, network setup via nmtui, hardware/log inspection tools, chroot shell — plus VT palette remapping so even rescue TTYs match brand green-on-dark.

Background + entry paths: The AcreetionOS Recovery Environment.

ACRECOVERY partition maturation

Payload compression tightened (gzip -9 under GRUB gzio), footprint trimmed ~800→512 MiB class, fast-boot target design (no network-online waits, hidden 1s menu), automatic failover via grubenv recordfail tracking with boot-success flag clearing.

Operator view: Managing the ACRECOVERY Partition.

Installer & first-run polish

  • Calamares disk-detection storage stack updated (QT6 generation)

  • postinstall.sh now configures Timeshift on day one — snapshots from first boot

  • Start-x session fixes, terminal replacement QA’d, firmware error reduction via mkinitcpio-firmware inclusion

Squashfs compression switch

ISO build switched back to XZ-compressed squashfs for higher density than EROFS provided — smaller downloads, same live experience.

Ongoing streams

  • Kernel/Mesa cadence follows upstream closely (gaming/VA-API gains arrive automatically)

  • PipeWire stack bumps land regularly

  • Package set pruning continues per minimal-ISO policy (Changes.md documents each removal)

Attention-flagged updates

Anything requiring user action gets an entry in Upgrade & Migration Notes instead — this page stays good news only.
