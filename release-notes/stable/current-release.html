Current ISO Build

Fresh from the download page. Exact package versions ship at build time — this page describes shape and intent.

Included stack

Piece State in current build

Kernel

Current stable linux series + matching headers/firmware

Desktop

Cinnamon with AcreetionOS dark-green branding, Nemo, GNOME Terminal

Installer

Calamares incl. encryption + dual-boot flows (Calamares Installer Walkthrough)

Recovery

Live Recovery Environment TUI + optional ACRECOVERY provisioning step (The AcreetionOS Recovery Environment)

Snapshots

Timeshift pre-configured RSYNC mode active after install

Audio/net

PipeWire stack · NetworkManager (+ nmtui)

Boot

GRUB w/ os-prober dual-boot detection, Plymouth splash, syslinux fallback on BIOS media

Post-install expectation

First pacman -Syu brings you fully current (rolling reality) — treat the ISO as a launchpad, not a museum piece. Guidance: Post-Installation Setup.

Verification

SHA256 alongside download link; verification steps: Downloading & Verifying the ISO.

Historical builds

Older ISOs remain downloadable but unsupported once superseded — rolling means current or nothing. Upgrade path for installed systems = updates, not re-downloads (Upgrade & Migration Notes).
