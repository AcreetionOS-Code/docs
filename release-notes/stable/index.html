AcreetionOS Release Notes

AcreetionOS rolls continuously; ISOs are refreshed snapshots of it. This component tracks both.

Reading order

  • Current ISO — what fresh downloads contain

  • Update highlights — notable changes landing via pacman

  • Upgrade notes — actions needed before/after specific updates

  • Known issues — open problems + workarounds, kept honest

The rolling contract

Your system doesn’t "upgrade to a version" — it stays current:

sudo pacman -Syu        # that's the whole ceremony

Version-ish anchors exist for support conversations: pacman -Q linux, ISO build date on download page.

Changelog culture

Detailed engineering log lives in the source repo’s Changes.md (GitHub org); these pages translate it into human. Community discussion happens on the main site channels — links in Contributing.
