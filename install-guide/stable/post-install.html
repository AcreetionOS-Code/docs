Post-Installation Setup

You rebooted into Cinnamon. Fifteen focused minutes finish the job.

1. Full update

sudo pacman -Syu

(Why even fresh ISOs update: rolling repo moved since build day — Updating AcreetionOS Safely.)

2. Baseline snapshot

sudo timeshift --create --comments "clean install baseline"

Confirm schedule exists too — Timeshift Snapshots on AcreetionOS.

3. Hardware-specific passes

Machine has Do

NVIDIA GPU

NVIDIA Drivers

Wi-Fi flaky

Wi-Fi guide

Printer/scanner

Printers & Scanners

Laptop

power setup

Dual-boot Windows

Verify menu per Installing Alongside Windows

4. Security quick-pass

sudo pacman -S ufw && sudo ufw enable        # firewall

Consider encryption retrofit planning (needs reinstall usually): Disk Encryption on AcreetionOS. Review who has sudo: Users, Groups & Sudo.

5. Make it yours

  • Themes/wallpapers: System Settings (brand palette lives in our site theme too)

  • Startup apps: trim early — faster logins forever

  • Software round-up: browser, editor, media player — patterns in Installing Software

6. Know your escape hatch

Bookmark Recovery Environment — F9/failover entry, Timeshift restore, package repair. Reading it BEFORE disaster is a superpower.

Done!
