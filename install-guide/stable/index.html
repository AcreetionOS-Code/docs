Installing AcreetionOS

Welcome aboard. This guide covers every step from empty USB stick to logged-in desktop.

The path at a glance

  1. Check requirements — 2 minutes

  2. Download & verify the ISO — 10 minutes of waiting

  3. Write it to USB — 5 minutes

  4. Prepare firmware if needed — usually nothing

  5. Boot the live session, try everything

  6. Run the installer — ~10 minutes

  7. Reboot into your new system → final touches
