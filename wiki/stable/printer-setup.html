Printers & Scanners

Modern printers are mostly driverless (IPP Everywhere/AirPrint); older ones need vendor drivers. Both paths covered.

Fast path (most printers made after ~2010)

sudo pacman -S cups system-config-printer
sudo systemctl enable --now cups.service

Then open System Settings → Printers (or CUPS web UI) → Add. Your printer appears via mDNS discovery; pick everywhere/driverless when offered.

HP printers

HP’s plugin covers older models and scanners:

yay -S hplip            # repo package if present; else AUR
hp-setup -i             # guided install incl. plugin download

Epson / Canon / Brother

  • Epson: epson-inkjet-printer-escpr (repo/AUR).

  • Canon: proprietary drivers live in the AUR (cnijfilter2-* per model).

  • Brother: AUR has brother-*-lpr-driver/cupswrapper pairs — install both, then add printer normally.

See AUR & yay if you’re new to AUR installs.

Printing test

lpstat -p                       # list printers
lp -d PrinterName /usr/share/cups/data/testprint

Queue management lives at localhost:631/jobs.

Scanning

sudo pacman -S sane simple-scan
scanimage -L                    # detect scanner
simple-scan                     # GUI

HP multi-function units may additionally want hp-plugin -i.

Nothing detected?

  • Same network subnet as the printer (guest-WiFi isolation blocks discovery).

  • USB printer: lsusb shows it? Then cups service actually running?

  • Firewall blocking mDNS: allow 5353/udp per Firewall Basics.
