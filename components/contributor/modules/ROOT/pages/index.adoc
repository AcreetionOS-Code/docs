== Where the work lives

Everything hangs off https://github.com/AcreetionOS-Code[the GitHub org] — layout map in xref:repo-layout.adoc[]. Docs (this site) build with Antora; content fixes are pull requests away.

== Ground rules

* Rolling-release discipline applies to contributors too — test against current, not ancient
* Reproduce before reporting; document after fixing
* Be excellent to each other; maintainers volunteer time like everyone else

== First contribution ideas

. Typos/unclear passages here → PR them (seriously, docs hunger)
. Run current ISO in a VM weekly (xref:testing.adoc[]) and note regressions early
. Package something from your toolkit per xref:packaging.adoc[]
