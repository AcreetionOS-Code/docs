= Post-Installation Setup
:description: Final setup after installing AcreetionOS: first update, snapshot baseline, drivers, firewall and personalization checklist.
:keywords: after installing linux checklist

You rebooted into Cinnamon. Fifteen focused minutes finish the job.

== 1. Full update

[source,bash]
----
sudo pacman -Syu
----

(Why even fresh ISOs update: rolling repo moved since build day — xref:wiki::updating-system.adoc[].)

== 2. Baseline snapshot

[source,bash]
----
sudo timeshift --create --comments "clean install baseline"
----

Confirm schedule exists too — xref:wiki::timeshift-snapshots.adoc[].

== 4. Security quick-pass

[source,bash]
----
sudo pacman -S ufw && sudo ufw enable        # firewall
----

Consider encryption retrofit planning (needs reinstall usually): xref:wiki::disk-encryption.adoc[]. Review who has sudo: xref:wiki::users-sudo.adoc[].

== 5. Make it yours

* Themes/wallpapers: System Settings (brand palette lives in our site theme too)
* Startup apps: trim early — faster logins forever
* Software round-up: browser, editor, media player — patterns in xref:wiki::installing-software.adoc[]

== 6. Know your escape hatch

Bookmark xref:wiki::recovery-environment.adoc[Recovery Environment] — F9/failover entry, Timeshift restore, package repair. Reading it BEFORE disaster is a superpower.

== Done!
