== Firmware notes

* **UEFI machines**: disable Secure Boot for installation (re-enableable later with custom keys). See xref:bios-uefi.adoc[].
* **Legacy BIOS**: fully supported; installer uses MBR/msdos labeling there.

== GPU reality

* Intel/AMD: open-source stack included, zero setup.
* NVIDIA: live desktop runs on Nouveau; proprietary driver is a post-install task (xref:wiki::nvidia-drivers.adoc[]).

== Peripherals that "just work"

Standard keyboards/mice, most Wi-Fi (linux-firmware included), USB hubs, webcams (UVC), audio via PipeWire. Exotic RAID/fake-RAID laptop modes should be switched to AHCI in firmware first — see xref:bios-uefi.adoc[].

== Virtual machines

Welcome: 2 vCPU / 4 GB / 25 GB minimums, details in xref:wiki::virtualization.adoc[Virtual Machines].
