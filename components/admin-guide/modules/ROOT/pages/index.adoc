== Assumed background

Comfortable in a shell; willing to read man pages (`man pacman.conf` etc. referenced throughout). Root access via sudo per xref:wiki:users-sudo.adoc[].

== The one rule that rules them all

Rolling release discipline: *no partial upgrades*. Everything else is negotiable craft.

Start wherever your problem lives — each chapter stands alone.
