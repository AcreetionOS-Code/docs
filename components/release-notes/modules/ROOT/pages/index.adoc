== The rolling contract

Your system doesn't "upgrade to a version" — it stays current:

[source,bash]
----
sudo pacman -Syu        # that's the whole ceremony
----

Version-ish anchors exist for support conversations: `pacman -Q linux`, ISO build date on https://acreetionos.org/download.html[download page].
