Welcome! This is the official knowledge base for https://acreetionos.org[AcreetionOS], a rolling-release Linux distribution built on the rock-solid Arch base and tuned for real-world usability out of the box.

== Why you'll like AcreetionOS

* **Arch power, none of the pain** — a curated Arch-based system that installs in minutes with a graphical installer.
* **Cinnamon desktop** — familiar layout, fast workflow, no learning curve.
* **Recovery built in** — a Windows-RE-style recovery environment and automatic Timeshift snapshots from day one.
* **Your own repos** — AcreetionOS ships its own signed repositories so updates are tested before they reach you.
